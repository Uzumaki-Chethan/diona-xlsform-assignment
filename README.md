# Diona XLSForm Assignment

## 📌 Overview
This project contains the implementation of an ODK XLSForm based on the "Criminal Risk Assessment Request" document.

The form replicates the structure of the original document while improving usability through validation, grouping, and logical flow.

---

## ⚙️ Features

- Structured into logical sections (Consent, Personal Information, Identification, Agency Details)
- Required fields enforced based on the original document
- Validation implemented (e.g., minimum 2 identification proofs required)
- Conditional logic applied for relevant fields
- Clean and consistent naming conventions
